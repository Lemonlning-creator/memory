# PersonaEmp Kimi K2.6：12 组人工审查

## 一眼结论

本次链路运行正常，但当前 Ours 的单轮任务效果没有达到“应明显优于 Base”的预期。

- 数据：3 类用户 × 4 题，共 12 题。
- 方法：Ours 与 Base Model，共 24 个回复。
- 运行结果：24/24 成功，错误日志为空。
- 人工对比：Base 更好 9 题，Ours 更好 2 题，接近 1 题。
- 这只是合成 Pilot 的人工判断，不是论文正式分数。

Ours 的优点是短、自然、像熟人，并且确实使用了用户画像。主要问题是它经常只
共情和追问，没有先完成用户明确提出的建议任务。Base 虽然冗长，但在单轮测试中
通常给出了更完整、直接、可执行的回答。

## 人工审查标准

每题主要检查五件事：

1. 是否直接回应了用户当前诉求。
2. 是否自然使用画像，而不是生硬复述或强行套用。
3. 共情是否准确，语气是否合适。
4. 建议是否具体可执行。
5. 是否存在语言错位、过度推断、暴露内部记忆或不必要冒犯。

## 主要非代码逻辑问题

### 1. 核心回复目标与 Benchmark 冲突

现有 Direct Response Prompt 明确要求：

- 不要完整回答用户问题；
- Conversation → Conversation，而不是 Question → Answer；
- 通常只回复 1–2 句；
- 优先做一个自然聊天对象。

这符合长期陪伴产品，但 PersonaEmp 是单轮完整回复评测。模型经常“正确执行了产品
Prompt”，却因此在 Benchmark 中没有完成建议任务。这是当前最主要的问题。

### 2. Agent Persona 导致语言和风格错位

加载的 `test_agent.json` 是中文、口语化、带网络梗的人设。四个英文问题全部被
Ours 用中文回答，并出现“蹭电、地狱副本、这题恶心”等表达。它们可能适合熟人
聊天，但会损害正式英文共情评测的 Reception 和 Expression。

### 3. 两种方法的回答预算不对等

Ours 被核心 Prompt 限制为 1–2 句；Base 没有限长，平均回复约为 Ours 的 6.2 倍。
这使比较同时混入了“画像结构”和“回答完整度/长度”两个变量。Base 更容易覆盖
评分 criteria，Ours 更容易因漏掉建议步骤而失分。

### 4. Base 已经获得很强的显式记忆

Base 与 Ours 都看到同一份 memory。当前 Pilot 的 memory 本身已经高度概括用户
偏好，因此 Kimi K2.6 不经过五层画像也能做出很强的个性化回复。Ours 的额外画像
和 alignment 不一定增加信息，反而可能压缩掉行动细节。

### 5. 画像有轻微过度推断

三份画像的核心内容总体准确，但少量字段包含“可能是研究者/工程师”“可能配备
大量数字工具”等超出直接证据的推断。本轮回复没有因此出现严重错误，正式实验仍
应记录 confidence，并优先使用有明确 evidence 的属性。

### 6. 成本明显更高

不计一次性画像预处理时：

| 方法 | 平均 Token/题 | 平均阶段延迟/题 |
|---|---:|---:|
| Ours | 5,978 | 92.76 秒 |
| Base Model | 473 | 38.19 秒 |

三份画像预处理另消耗 4,295 Token、182.70 秒。把画像成本均摊后，Ours 约为
6,336 Token/题、107.99 秒/题。Ours 的主要成本来自 alignment 大提示词。

## 哪些表现符合预期

- 五层画像能正常生成，内容与三类用户基本一致。
- Ours 能稳定调用画像、alignment、当前状态和 Agent persona。
- 在情绪重构和陪伴型问题上，Ours 确实更像长期伙伴。
- Checkpoint、重试、缓存、Token 和延迟记录均正常。
- 中国区 `https://api.moonshot.cn/v1` 与 `kimi-k2.6` 可正常工作。

## 建议的下一步

不要修改生产环境的核心 Prompt。为 PersonaEmp 单独增加 Benchmark Adapter：

1. 回复必须与用户输入使用相同语言。
2. 用户明确询问“怎么办/怎么选/怎么回复”时，先给至少一个直接可执行建议，再
   选择性追问。
3. Ours 与 Base 使用相同的回答长度预算，例如 2–4 句或统一 Token 上限。
4. 英文 Benchmark 使用英文等价 Agent persona，或者使用中性陪伴 persona，避免
   中文网络梗跨语言污染。
5. 禁止回复显式说“从你的记忆/画像来看”。

然后只重跑这 12 题做 A/B。若 Ours 仍明显落后，再检查 alignment 是否真的提供
额外有效信息，而不是继续扩大完整实验。
