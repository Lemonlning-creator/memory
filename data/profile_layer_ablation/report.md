# 五层用户画像逐层消融实验报告

**运行时间：** 2026-07-21  
**实验目标：** 验证删除 `core`、`regulation`、`cognition`、`identity`、`behavior` 五个画像层之一后，智能体回复及用户画像激活是否发生变化。

## 1. 实验设计

- 画像：`dataset/test_user.json` 中的五层静态画像；智能体人设为 `dataset/test_agent.json`。
- 用例：5 个中文单轮输入，分别定向触发核心诉求、压力调节、决策/表达方式、科研身份场景和长期工具偏好。
- 条件：完整画像（基线）及 5 个单层删除条件，共 30 个「用例 × 条件」组合。
- 控制：每个组合使用完全相同的用户输入、智能体人设、生成参数（temperature=0）；删除只作用于本次提示词，不会修改保存的原始画像。
- 记录：生成回复、激活的画像字段，以及独立模型评审的相关性、个性化、帮助性、自然度（1–5 分）。

## 2. 总体统计

| 条件 | 相关性 | 个性化 | 帮助性 | 自然度 | 相对完整画像的个性化变化 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 完整画像 | 4.6 | 4.0 | 3.4 | 5.0 | — |
| 删除 core | 4.6 | 4.0 | 3.0 | 5.0 | 0.0 |
| 删除 regulation | 4.8 | 4.2 | 3.6 | 5.0 | +0.2 |
| 删除 cognition | 4.8 | 4.2 | 3.2 | 5.0 | +0.2 |
| 删除 identity | 4.4 | 3.4 | 3.0 | 4.8 | -0.6 |
| 删除 behavior | 4.8 | 4.2 | 3.2 | 5.0 | +0.2 |

在这组小样本中，删除 **identity（身份/环境）层** 的总体负面影响最大：相关性下降 0.2、个性化下降 0.6、帮助性下降 0.4、自然度下降 0.2。其余层的总体均值没有稳定下降，不能据此认定它们无效。

## 3. 定向用例与激活校验

| 被测层 | 基线是否激活目标层 | 删除后是否仍激活目标层 | 删除后个性化变化 | 删除后帮助性变化 | 解释 |
| --- | --- | --- | ---: | ---: | --- |
| core | 是 | 否 | 0.0 | 0.0 | 删除在激活日志中生效；回复从“输入输出不对等”的成长焦虑转为“伪勤奋”猜测，关注点发生变化。 |
| regulation | 否 | 否 | 0.0 | -1.0 | 该用例未稳定触发调节层，只有帮助性下降可作弱证据。 |
| cognition | 否 | 否 | +1.0 | 0.0 | 该用例未稳定触发认知层；评审差异受措辞随机性影响，不能解释为删除带来改进。 |
| identity | 否 | 否 | 0.0 | +1.0 | 该身份场景也未稳定触发身份层，因此单用例证据不足。 |
| behavior | 是 | 否 | 0.0 | -1.0 | 删除在激活日志中生效；基线给出“Obsidian + 固定复盘习惯”，删除后退化为更泛化的流程建议。 |

其中 `core` 和 `behavior` 两个定向用例满足了“基线激活、删除后不再激活”的结构性验证；其余三个用例的激活提示未能可靠选中目标层，需要改进用例或激活器后再作因果判断。

## 4. 典型回复差异

### 行为层：长期工具偏好

- **完整画像：** “工具越花哨越容易成负担……极简的笔记库（如 Obsidian）+ 固定的复盘习惯。”
- **删除 behavior：** “笔记要能‘长’出来……流程得极简，少折腾配置。”

删除行为层后仍保持相关，但失去具体工具偏好和可执行的长期习惯建议，帮助性评分由 4 降至 3。

### 核心层：成长与意义诉求

- **完整画像：** 将焦虑理解为“输入输出不对等”，追问笔记整理和知识贯通。
- **删除 core：** 改为推测“伪勤奋”或逃避深度思考。

这说明核心层改变了回复对用户担忧的归因；不过本次评审分数未下降，意味着当前单轮短回复指标对这种语义偏移不够敏感。

## 5. 结论与下一步

1. 本轮最明显的总体信号是：身份层与回复质量相关，尤其影响个性化；但它的定向激活未成功，因此该结论应视为**待复验的线索**，而非最终定论。
2. 核心层与行为层已通过“删除后目标层不再激活”的结构性检查，并观察到回复归因或具体性下降，说明两层确实进入了生成链路。
3. 调节、认知、身份层的测试用例需要加强触发性，例如在输入中加入更明确的应对方式、表达偏好、职业角色与工作环境线索；随后每个条件至少重复 3 次并引入人工盲评。
4. 当前结果不能用来宣称“完整画像在所有指标上最好”：部分删除条件得分更高，主要可能来自单次生成波动、模型评审波动，以及基线目标层激活率仅为 40%。
