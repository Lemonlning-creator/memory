# 五层用户画像逐层消融实验报告

**运行时间：** 2026-07-21
**分支：** `feature/ablation-luoyi`
**实验规模：** 5 个画像派生用例 × 6 个画像条件 = 30 组

## 1. 本轮方法

用户画像来自 `dataset/test_user.json`。脚本从每层选取置信度最高的字段并自动构造一条定向输入，不再使用手写 `CASES`。

| 层级 | 选用字段 | 输入关注点 |
| --- | --- | --- |
| core | `desires` | 长期学习、知识整合与长期价值 |
| regulation | `control` | 规划、结构化与控制需求 |
| cognition | `expression style` | 结构化表达和问题拆解 |
| identity | `occupation` | 科研、算法或软件开发背景 |
| behavior | `content preferences` | AI、认知科学和科研方法偏好 |

每条输入在完整画像、删除 `core`、删除 `regulation`、删除 `cognition`、删除 `identity` 与删除 `behavior` 下各运行一次。删除仅限制智能体本轮可见的画像信息，不改变被评估用户本身。

### 评分与激活

- **激活判定：** 在回复生成后，根据用户输入、实际回复与可用画像判断实际回复使用了哪些字段；行为层判定已纳入“按兴趣偏好选择话题/建议方向”的语义规则。
- **质量评分：** 评审模型获得完整用户画像，并被要求代入该用户的视角评分。它评价的是“这位具体用户会不会认为该回复贴合、有帮助且自然”，而不是泛化的旁观者评分。

## 2. 总体结果

分数为 1–5 分的均值。

| 条件 | 相关性 | 个性化 | 帮助性 | 自然度 |
| --- | ---: | ---: | ---: | ---: |
| 完整画像 | 3.0 | 1.6 | 2.0 | 2.8 |
| 删除 core | 3.4 | 3.0 | 2.4 | 3.8 |
| 删除 regulation | 3.4 | 2.4 | 2.2 | 3.6 |
| 删除 cognition | 3.0 | 1.8 | 2.0 | 3.2 |
| 删除 identity | 3.0 | 2.4 | 1.8 | 3.2 |
| 删除 behavior | 3.2 | 2.0 | 2.0 | 3.2 |

新的“用户视角”评分比旧的泛化评分严格得多：完整画像的个性化均值仅 1.6，说明当前生成回复虽然会引入画像字段，但还没有稳定把这些信息转化为用户真正感到贴合、可执行的建议。

完整画像并未在所有总体指标上胜过删除条件。该结果不能解释成“删除画像更好”：本实验每个条件只生成一次，且短回复存在明显生成波动；更重要的是，完整画像提示中较多画像信息可能使模型倾向于泛化地“调侃/追问”，而不是围绕当前需求做具体建议。

## 3. 定向激活校验

| 被测层 | 完整画像下目标层激活 | 删除后目标层激活 | 个性化变化（删除－完整） | 帮助性变化（删除－完整） |
| --- | --- | --- | ---: | ---: |
| core | 是 | 否 | 0.0 | -1.0 |
| regulation | 是 | 否 | 0.0 | 0.0 |
| cognition | 是 | 否 | 0.0 | 0.0 |
| identity | 是 | 否 | +1.0 | -1.0 |
| behavior | 否 | 否 | +1.0 | 0.0 |

`core`、`regulation`、`cognition` 与 `identity` 在完整画像下均成功激活，并且在对应层删除后不再激活，验证了四个消融开关的结构性有效性。

行为层仍未在自己的定向用例中激活。原因不是激活器忽略了关键词：本轮完整画像回复只说“偏好听着很硬核”，随后泛化地追问近期阅读内容，未基于 AI/认知科学/科研方法偏好选择具体话题、推荐或建议。因此按更新后的判定规则不应把它记为行为层激活。行为层用例需要改为要求明确的内容选择，例如“在 AI、认知科学和科研方法中，帮我选一个值得深入的方向并说明原因”。

## 4. 典型回复

### 核心层

- **完整画像：** 建议从“最让你兴奋的小点”深挖，将长期价值与实际行动连接起来。
- **删除 core：** 退化为“先把最近学到的知识点串成线”的一般性建议。

完整画像下帮助性为 2 分，删除核心层后降为 1 分，显示核心目标能改善建议方向，但当前回复仍不够具体。

### 调节层

- **完整画像：** 识别“过度规划”可能阻碍行动，并询问具体卡点。
- **删除 regulation：** 仍然依赖科研/算法身份和“完美体系”线索给出建议。

两者评分相同，表明其他层可提供部分重叠信息；这不是调节层未被使用，因为激活日志已确认该层在基线被调用。

### 行为层

- **完整画像：** “与其给建议，不如直接聊聊你最近在看什么？”
- **删除 behavior：** 仍从当前用户输入提及的 AI 概念延续话题。

两条回复都没有根据画像中的内容偏好作出足够明确的内容选择，因此行为层的因果贡献仍未被本轮验证。

## 5. 结论与下一步

1. 四个层级（core、regulation、cognition、identity）已通过“基线激活、对应删除后不激活”的结构性检查。
2. 用户视角评分揭示了生成侧的主要问题：画像被调用不等于回复真正个性化。当前回复的帮助性与个性化仍偏低。
3. 行为层需要更强的、要求模型实际作内容选择或推荐的测试输入；当前“你会怎么给建议”不足以触发内容偏好字段。
4. 后续应对每个条件至少重复 3 次，并加入人工盲评；同时把回复生成提示改为优先给出与画像匹配的具体建议，而非仅确认、调侃或追问。
