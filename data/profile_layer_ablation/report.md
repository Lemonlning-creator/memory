# 五层用户画像逐层消融实验报告

**运行时间：** 2026-07-21
**分支：** `feature/ablation-luoyi`
**实验目标：** 检验删除 `core`、`regulation`、`cognition`、`identity`、`behavior` 任一画像层后，对话回复质量与画像激活是否发生变化。

## 1. 本次实验的输入来源

用户画像直接来自 `dataset/test_user.json`，不再使用手工编写的 `CASES`。脚本从每个画像层选取置信度最高的字段，并以该字段值自动构造一个定向输入：

| 层级 | 选用字段 | 自动生成输入的关注点 |
| --- | --- | --- |
| core | `desires` | 长期学习与知识整合目标 |
| regulation | `control` | 规划、结构化与控制需求 |
| cognition | `expression style` | 结构化表达和问题拆解 |
| identity | `occupation` | 科研/算法/软件开发工作背景 |
| behavior | `content preferences` | AI、认知科学与科研方法偏好 |

每个输入在完整画像与五种“仅删除一个层级”的配置下各运行一次，共 **30 组**。所有条件保持智能体人设、用户输入和生成参数（temperature=0）一致；删除只作用于当次提示词，不修改源画像。

## 2. 总体结果

评分为独立模型评审的 1–5 分均值，分别衡量相关性、个性化、帮助性与自然度。

| 条件 | 相关性 | 个性化 | 帮助性 | 自然度 | 相比完整画像的帮助性变化 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 完整画像 | 4.4 | 4.4 | 3.4 | 5.0 | — |
| 删除 core | 4.4 | 4.0 | 3.0 | 5.0 | -0.4 |
| 删除 regulation | 4.2 | 4.0 | 2.8 | 5.0 | -0.6 |
| 删除 cognition | 4.4 | 4.4 | 3.4 | 5.0 | 0.0 |
| 删除 identity | 4.2 | 4.2 | 3.2 | 5.0 | -0.2 |
| 删除 behavior | 4.0 | 4.0 | 3.2 | 4.8 | -0.2 |

从总体均值看，**regulation（调节）层** 的删除带来最大帮助性下降（-0.6）；**behavior（行为偏好）层** 的删除带来最大的相关性下降（-0.4）和唯一的自然度下降（-0.2）。`cognition` 在本轮均值中未呈现可测下降。

## 3. 定向激活与同层对照

| 被测层 | 基线目标层激活 | 删除后目标层激活 | 个性化变化 | 帮助性变化 | 结论 |
| --- | --- | --- | ---: | ---: | --- |
| core | 是 | 否 | 0.0 | -2.0 | 层删除生效，且对建议的具体帮助影响明显。 |
| regulation | 是 | 否 | -2.0 | -1.0 | 层删除生效，是本轮最强的单用例个性化损失。 |
| cognition | 是 | 否 | 0.0 | 0.0 | 层删除在激活上生效，但该单例的质量评分不敏感。 |
| identity | 是 | 否 | 0.0 | 0.0 | 层删除在激活上生效，回复仍能从其他层获取相近线索。 |
| behavior | 否 | 否 | +1.0 | 0.0 | 基线未成功激活目标层，不能据此判断行为层无效。 |

完整画像下，五个定向输入中有四个成功激活目标层（80%）；在对应层被删除时，`core`、`regulation`、`cognition`、`identity` 四层都不再激活，验证了消融开关的结构性有效性。

## 4. 典型差异

### 调节层：规划与控制需求

- **完整画像：** “别被‘完美体系’困住，先跑通最小闭环，再迭代。”
- **删除 regulation：** “别光规划呀，具体是哪个难题卡住你了？”

删除调节层后，回复保留了泛化的科研身份线索，但失去了对“控制/结构化作为应对方式”的准确识别；个性化从 5 分降到 3 分，帮助性从 3 分降到 2 分。

### 核心层：长期学习目标

- **完整画像：** 建议以一个具体小项目“边做边连”，回应知识整合的长期目标。
- **删除 core：** 改为一般性的“小目标/一个模块”建议。

两种回复都相关，但删除核心层后帮助性从 4 分降到 2 分，说明核心目标有助于把泛化的任务拆解建议转化为更贴合长期诉求的方向。

### 行为层：内容偏好

行为层的基线没有被激活，删除后的质量变化不能作为层级效应。该问题说明基于“内容偏好”字段生成的当前输入仍不足以稳定触发画像激活器，需要在下一轮用例中更明确地要求 AI/科研内容推荐或方法选择。

## 5. 结论与限制

1. 当前证据支持 `regulation` 与 `core` 层对个性化和帮助性具有直接作用：两层均在基线被激活，删除后不再激活，且同层用例评分下降。
2. `identity` 与 `cognition` 层完成了结构性消融验证，但单次回复评分未下降，可能是其他画像层能够提供重叠线索。
3. `behavior` 层的用例没有稳定触发，不能根据本轮分数判断其贡献，需要重新设计该层的输入。
4. 每个条件仅运行一次，且质量评分来自模型评审；结果应作为可复现的初步信号。下一轮建议每个条件重复至少 3 次，并使用人工盲评或多评审器降低生成与评分波动。
