# 本版的“训练”到底是什么

**V9 没有 SFT、LoRA、GRPO、DPO 或其他参数训练。没有训练轮数、学习率、优化器、训练权重或训练 checkpoint。**

所有 Ours 阶段调用远程 `deepseek-v4-flash`。从 Ca 提取 Self Domain 是推理时编译人物画像，不是微调；从 Cb 已完成 session 更新 User Domain 是结构化状态更新，不是训练模型权重。代码中的 `train_chat` 是论文 Ca 的历史命名。

本地下载的 RoBERTa/BERTScore 模型只是评价器，用于前向推理计算标签/相似度。它们也没有在 REALTALK 上训练。

## 为什么表中还有 w/ FT

论文 Table 2 包含论文作者的 w/o fine-tune、w/ fine-tune 两行。本包引用这两行作为参考，并在下面增加 Ours V9，不重新训练或复跑它们。

不能写成“Ours 复现了论文微调训练”，也不能将论文训练方法视为本版已实现。论文没有披露完全相同的基础模型运行配置，因此横向展示属于协议对齐比较，不是只有单一变量不同的严格控制实验。
